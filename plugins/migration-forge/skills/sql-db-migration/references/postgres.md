# PostgreSQL notes

## Upgrade paths
- **`pg_upgrade --link`:** minutes of downtime and same host. Run `--check` first. After it finishes, run `vacuumdb --all --analyze-in-stages`.
- **Logical replication** (publication/subscription): near-zero downtime across major versions or hosts.
  - DDL and sequences are **not** replicated. Copy the schema first, and set sequences at cutover.
  - Every table needs a primary key or `REPLICA IDENTITY FULL`.
- **pg_dump/pg_restore:** use `-Fd -j N` for parallelism. Simple, with downtime proportional to size.

## Lock-safe DDL (squawk flags most of these)
| Change | Safe form |
|--------|-----------|
| add index | `CREATE INDEX CONCURRENTLY` (outside a transaction; retry if INVALID) |
| add FK | `ADD CONSTRAINT … NOT VALID`, then `VALIDATE CONSTRAINT` |
| add NOT NULL | `CHECK (col IS NOT NULL) NOT VALID` → `VALIDATE` → `SET NOT NULL` (PG ≥12 uses the check) |
| add column with default | non-volatile defaults are instant on PG ≥11. Volatile ones (e.g. `random()`) rewrite the table |
| change type | new column + backfill + swap (expand/contract). `ALTER TYPE` rewrites the table |
| rename | expand/contract with a view or a dual column. Never in the same release as the code change |

Always use `SET lock_timeout = '5s'; SET statement_timeout = '15min';` in migrations.

## Gotchas when migrating INTO Postgres
- Identifiers are folded to lower case unless quoted. Port mixed-case names consistently.
- Text comparison is case-sensitive. Use `citext` or `lower()` indexes where legacy relied on case-insensitive collation.
- `serial` → prefer `GENERATED BY DEFAULT AS IDENTITY`. After a copy, run `SELECT setval(pg_get_serial_sequence('t','id'), max(id)) FROM t;`.
- Timestamps: pick `timestamptz` for instants and store UTC. Use `timestamp` only for wall-clock values.
- `NUMERIC` without a scale keeps arbitrary scale. Specify `(p,s)` to match the legacy rounding.
- Empty string vs NULL from Oracle sources.
- Tools: **pgloader** (MySQL/SQL Server/SQLite → PG, with type casting rules), **ora2pg** (Oracle).
